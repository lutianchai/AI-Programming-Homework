## 任务二：LeNet-5 实现报告

### 1. 结构说明
本实验实现了经典的 LeNet-5 网络，相比任务一中的极简 CNN，增加了卷积层的深度（2层）和全连接层的宽度。采用了 ReLU 作为激活函数以加速收敛。

### 2. 训练参数
- **优化器**: Adam (LR=0.001)
- **Batch Size**: 64
- **设备**: NVIDIA RTX GPU (CUDA 加速)
- **测试集准确率**: ~98.2%

### 3. 模型对比
| 指标 | 极简 CNN | LeNet-5 |
| :--- | :--- | :--- |
| 参数量 | 较少 | 约 60,000 |
| 准确率 | 约 92% | 约 98% |
| 收敛速度 | 快 | 稳健 |

**分析**：LeNet-5 通过多层卷积有效提取了空间特征，虽然计算量略大，但在手写数字识别任务上表现远优于单层极简结构。
